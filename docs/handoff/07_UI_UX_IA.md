# UI/UX NAVIGATION & IA

Bottom navigation: Beranda, Kasir, Riwayat, Lainnya. Top-right: sync status + notifications.

Beranda Owner/Manager: Omzet Hari Ini, Pengeluaran, Laba Kotor, trend, recent activity, drilldown. Cashier dashboard simpler.

Kasir: Take Away default, Dine In, Delivery, Ojol; search, category, Grid/List, menu picker, product config, cart, Saved Bill, customer, checkout. No menu photos.

Product configuration: Variant, Modifikasi, Paket, note, quantity, price/custom price; required min/max must be valid before add.

Cart: simple/persistent side panel on larger screens, floating cart on smaller screens. Saved Bill, discount, totals, customer/order info, checkout.

Checkout: Cart → Checkout → Customer/Order Info → Payment → Success. Payment Cash/QRIS/Transfer + split.

Success: total/payment/change, receipt, WhatsApp share, print, close.

Riwayat: search/filter/date/sort/pagination; canceled red. Detail = digital receipt + separate change history/audit.

Lainnya groups: Operational (Shift/Uang Dompet, Expense, Pemasukan Lain), Data (Customer/Menu/Category/Variant/Modifikasi/Paket), Approval, Reports, System (Notifications/Settings/Backup where authorized).

Visual direction: clean, modern, operational, slightly premium; avoid excessive gradients/colors/card-heavy decoration. User's separate UI/UX reference is authoritative visually. Legacy UI must not be copied. Responsive phone/tablet and accessible.
